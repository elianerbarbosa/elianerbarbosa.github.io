# Portfólio — Eliane Ramos Barbosa

> Portfólio pessoal e profissional de **Eliane Ramos Barbosa** — Analista de Inteligência de Dados & Engenheira de Produção.

## 🔗 Demo ao vivo

Acesse em: **[elianerbarbosa.github.io](https://elianerbarbosa.github.io)**

## ✨ Funcionalidades

- **Animação de digitação** no nome principal
- **Player de áudio** com fade in/out automático ao rolar até a seção Motivação
- **Carrossel de projetos** com suporte a touch/swipe
- **Formulário de contato** com validação acessível e integração via FormSubmit
- **Reveal on scroll** para animações de entrada dos elementos
- **Nav highlight** — link ativo muda ao rolar entre seções
- **Menu mobile** acessível com Escape e click fora para fechar
- **Responsivo** — funciona de 320 px até telas 4K
- **Acessível** — skip link, aria-labels, contraste WCAG AA, focus-visible, reduced-motion

## 🛠 Tecnologias

| Tecnologia | Uso |
|---|---|
| HTML5 semântico | Estrutura e acessibilidade |
| CSS3 custom properties | Design system com tokens |
| JavaScript ES6+ (vanilla) | Interatividade modular |
| Font Awesome 6 | Ícones |
| Google Fonts (Sora + Plus Jakarta Sans) | Tipografia |
| FormSubmit | Backend de formulário sem servidor |
